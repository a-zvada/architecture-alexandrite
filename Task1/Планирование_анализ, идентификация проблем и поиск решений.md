# Планирование

## Существующие проблемы

*   просроченные заказы и жалобы клиентов
*   низкая производительность АРМ MES.
*   отстуствие автоматизации развертывания
*   долгое время расчета стоимости в MES. Для онлайн-заказа расчет в 30 минут — это очень долго.

## Потенциальные проблемы

*   низкая производительность и отказоустойчивосить при повышении нагрузки:
    *   отсуствие горизонтального масштабирования
    *   отсутсвие логирования, мониторинга и трейсинга запросов
*   дальнейшее увеличение времени внедрения новых фич:
    *   недостаточные ресурсы для реагирование на рост нагрузок
    *   недостаточная автоматизация тестирования
    *   разные технологии фронтенда и отсутствие ресурсов для разработки на React
    *   отсутcтвие в команде архитектора, системных аналитиков, из-за чего их функции возложены на разработчиков и тимлида
*   возможные уязвимости в API для B2B
